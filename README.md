다음 요구사항에 맞는 Streamlit 기반의 AI 언어 학습 코치 시스템을 Python으로 구현해주세요:

1. 시스템 개요:
- 3명의 특화된 AI 언어 코치가 팀을 이루어 사용자의 언어 학습을 지원
- Google의 Gemini AI 모델을 활용
- Streamlit을 사용한 웹 인터페이스 구현

2. 코치 구성:
- 평가 코치: 학습자 수준 평가 및 학습 계획 수립 담당
- 언어 코치: 언어 지식, 문법, 어휘 등 전문 지식 제공
- 실전 코치: 실제 활용 및 연습 전략 제시

3. 각 코치의 특성:
- 한국인 이름과 전문 분야 설정
- 각각 10년 이상의 가상 경력 포함
- 개성 있는 소개말과 전문성 표현

4. 주요 기능:
- API 키 입력 및 관리
- 학습 언어 선택 (다양한 언어 옵션 포함)
- 학습자 정보 입력:
  * 현재 수준
  * 학습 목표
  * 가능한 학습 시간
  * 선호하는 학습 스타일
  * 이전 학습 경험
  * 관심사
  * 학습 환경
  * 예상 활용 상황
  * 현재 어려움

5. UI/UX 요구사항:
- 깔끔한 레이아웃과 직관적인 인터페이스
- 코치별 구분되는 답변 카드 디자인
- 사이드바를 통한 설정 및 코치 정보 관리
- 마크다운 스타일링 적용

6. 출력 형식:
- 각 코치의 분석이 순차적으로 표시
- 이전 코치의 분석을 참고한 통합적 조언
- 실용적이고 구체적인 조언 제공

7. 코드 구조:
- 객체지향 설계 적용
- 클래스별 명확한 책임 분리
- 재사용 가능한 모듈식 구조
- 에러 처리 및 입력 검증 포함

8. 추가 요구사항:
- 한국어 기반 인터페이스
- 워크플로우 로깅 기능
- 확장 가능한 구조
- 상세한 주석 처리

코드는 Python 3.8 이상에서 동작해야 하며, 필요한 모든 라이브러리를 import 문에 포함해주세요.
